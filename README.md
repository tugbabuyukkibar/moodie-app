# Moodie app

Web app for the Moodie hair clip: pick the mood shown on the clip over Bluetooth
and see its battery level.

- **iPhone**: open the GitHub Pages link of this repository in the free
  **Bluefy** browser (Safari has no Web Bluetooth), then add it to the home screen.
- **Mac / Android**: open it in Chrome.

Generated from the Moodie project; don't edit here.
